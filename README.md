# 衆目 / THE HUNDRED EYES

ひとつのポスト、百の受け取り方。届くことと、聞こえることを、同じ暗闇の中で眺めるインタラクティブ・メディアアート。

**[作品を体験する → eyes.mintan.org](https://eyes.mintan.org)**

作者 [@uniminyo](https://x.com/uniminyo) · [English](./README.en.md) · [MIT License](./LICENSE)

[![暗闇に浮かぶ百の目と中央の投稿画面](./public/og/the-hundred-eyes.jpg)](https://eyes.mintan.org)

[Jev / TypeSafe](https://docs.typesafe.ai/introduction) のChoiceとScoreを、3D空間の視線・光・声へつなぐOSSのユースケースです。Next.js、React、Three.js、Web Audioで制作しています。[紹介用の概要・実装へのリンク](./docs/JEV-USE-CASE.md)

## 体験

ポストすると、近い目から遠い目へ一度だけ瞬きが伝わります。目は元の位置を保ち、固定の四人の直感が、届きやすい声として最初に浮かびます。Jevの「表に出したさ」が低くても、その人の持つ発信力は消えません。残りの目も暗闇に薄く残っています。

「ポストアナリティクス」を開くと、同じ100人の目が明るくなり、6種類の直感の人数が見えます。無関心が多い場合も、少ない場合も、判定された人数をそのまま表示します。「100人の内側」では、同じ目の画像と4つの感情を一覧内で開閉できます。

「書き直す」で同じ100人へ届け直すと、瞬きが繰り返され、各感情に前回比が表示されます。入力中には判定しません。同じ文章はセッション内で同じ結果を再利用します。手を止めると、自分の言葉と書き換えた跡が残り、最後に「その言葉は、誰のために。」が淡く現れます。

- 作品情報の **判定基準**：Jevに渡す6択、4軸の段階、人物に設定する状況、声の演出について読めます。画面とAPIは同じ定義を参照します。
- 分析表示の **Xでポスト**：現在の投稿文、直感の内訳、作品URLをXの投稿画面へ引き継ぎます。長い文章は共有用のコピーだけを省略し、Xの280文字換算に収めます。実際の公開はX上で本人が確定します。
- 目のパラメータはスクロールなしで表示し、100人の一覧はスクロールできます。
- スマホ、動きを減らす設定、WebGLが使えない端末の軽量表示に対応します。音は初期状態ではOFF。右上の「音 OFF」で環境音を有効にできます。

## ローカル起動

```sh
npm ci
npm run dev -- --port 3001
```

`http://localhost:3001` を開きます。キーがなければ、端末内の簡易ルールによる仮判定として動作します。

Jevへ接続する場合は、Git対象外の `.env.local` に次を設定します。

```dotenv
TYPESAFE_API_KEY=your_key_here
JEV_MODEL=jev-latest
```

サンプルは [.env.example](./.env.example) を参照してください。APIキーを `NEXT_PUBLIC_` 変数やソースコードに置かないでください。

## Jevと作品の関係

一人ごとに直感のChoiceと、関心・好意・不快・表に出したさの4つのScoreを判定します。100人で500問、25人ずつ4件のリクエストを並列に送ります。有効な100人分の応答が揃ってから作品へ反映し、失敗時は前の結果を保ちます。

人物像、短い台詞、声の届きやすさは作者が定義します。Jevが台詞を自由生成するわけではありません。無関心や批判の人数は固定せず、モデルの確信度を感情量として使いません。これは架空の100人による作品であり、実在の人間やXの統計ではありません。

最初に目立つのは、疑い・冷笑・献身・強い言葉への敏感さを持つ同じ四人です。Jevが返す直感や感情は変化しても、発信力の偏りは変わりません。その後のアナリティクスでは、100人をそれぞれ一人として数えます。

瞬きの順番と速さは演出です。Jevの処理順や実行時間の実測を表しません。ポストした文章のみTypeSafeへ送信し、入力途中の文章は送りません。

## 検証と公開

```sh
npm run lint
npm run build
npm run test:e2e
```

通常のテストは仮判定または合成応答を使い、JevやXに実投稿しません。ブラウザテストはPC・スマホ相当のChromiumと、一部のWebKitを使います。Playwrightのブラウザが未導入なら `npx playwright install` を実行してください。
