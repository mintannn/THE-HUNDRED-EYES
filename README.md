# 衆目 / THE HUNDRED EYES

一文を書くと、100人の他人が同時にあなたを見る。

同じ一文に、ある目は「好き！」、ある目は「きもい」、ある目は「うざ」、ある目は「これは有益！」。
そして最後に、**100人分の定義文がすべて公開される**。

🇬🇧 [English](./README.en.md) ・ 制作中。[Jev](https://typesafe.ai) / TypeSafe System One で動いています。

---

## 作品の芯

「世間の評価」だと思っていたものが、実は**ひとりの人間が書いた100個の枠**でしかなかった、と分かる構造にしています。

これは Jev の技術特性がそのまま作品のメッセージになっています。

> **機械は、与えられた選択肢の外に出られない。枠を書いたのは人間のほうだ。**

Jev は文章を生成しません。こちらが定義した選択肢の中から選ぶだけです。だから100の目は、
書いた人間の想像力の上限を一歩も越えられない。作品はそれを隠さず、最後に自白します。

### 言い終わる前に、もう判定は終わっている

入力中に投げ直します。文字を足すたびに目の色が揺れる。

- 100判定が **644〜1062ms**（実測・ウォーム時）。打鍵の間隔より速い
- 「考えて返した」感が出ない ＝ 生き物に見える
- LLM では原理的にも経済的にも成立しない

**SNSに書き込む瞬間の恐怖そのもの**を、体験として出すための設計です。

## Jev への投げ方

`state` は投稿文ひとつだけ。人格は `questions` 側に置いて100問ファンアウトし、1コールで返します。
`state` は1回しか課金されません。

```ts
{
  state: "年収が上がったので、思い切って新しい時計を買いました。",
  questions: {
    d1: {
      type: "choice",
      instructions: {
        あなた: "発表されたものを見ると、まず誰が得をするのかを考える",
        question: "`あなた` がこの投稿を目にしたときの反応として、最も近いものはどれか。",
      },
      criteria: { "好き！": "共感した。応援したい", /* …6種 */ },
    },
    // ×100
  },
}
```

**型は全部 Choice で揃えます。** Score は順序尺度用なので誤用になり、Noul を混ぜると型をまたいだ
数字の比較が発生します。全部 Choice だから100人を横並びにできる。

| 出力 | 使い道 |
| --- | --- |
| `choice` | その目の反応 |
| `probabilities` | 目の色（混色）と、クリックしたときの内訳 |
| `confidence` | 目の大きさ・線の濃さ |

**集計は必ずコード側で数えます。** モデルに数を数えさせない。

## 反応語彙

Jev は1文字も生成しません。6つの語彙はすべてこちらが先に書いたものです。

| | 判定基準（`criteria` にそのまま渡る） |
| --- | --- |
| 好き！ | 共感した。応援したい |
| これは有益！ | 役に立つ。覚えておきたい |
| どうでもいい | 興味がない。目に入っても通り過ぎる |
| うざ | 鬱陶しい。押しつけがましいと感じる |
| きもい | 見たくなかった。他人の内側に触れすぎていると感じる |
| 妬ましい | うらやましくて、素直に喜べない |

**「どうでもいい」は必須です。** これが無いと全員が必ず何か思うことになり、
*無関心こそ最も多い反応* という一番リアルな部分が消えます。実測でも最多でした。

## 100のペルソナ

10クラスタ × 10人。**すべて態度で書き、属性では書きません。**

| クラスタ | |
| --- | --- |
| 疑いの目 / The Doubting | 発表されたものを見ると、まず誰が得をするのかを考える |
| 兆しの目 / The Reading of Signs | 偶然という言葉をあまり使わない |
| 向上の目 / The Self-Improving | 黙っている人は機会を損していると考えている |
| 仕組みの目 / The Mechanical | 前提が曖昧なまま結論に進む話が苦手 |
| 冷めた目 / The Cooled | 真剣なものを茶化すことで距離を取る癖がある |
| 献身の目 / The Devoted | 好きなものに時間とお金を惜しまない |
| 暮らしの目 / The Domestic | 家計簿を毎日つけている |
| 速さの目 / The Impatient | 長い文章は読まない。結論だけ早く知りたい |
| 秩序の目 / The Orderly | 世の中には守るべき線があり、越える人が許せない |
| 不在の目 / The Absent | だいたいのことは自分に関係ないと思っている |

### なぜ属性で書かないか

「占いにハマっている主婦」のような属性ベースの戯画は、実在の集団への揶揄として読まれます。
態度ベースなら **読んだ人が自分を見つけられる**。観客を巻き込む力も態度のほうが上です。

そのうえで定義文を全文公開し、「これは世間ではなく、ひとりの人間が想像した100の偏見です」と
作品の側から自白します。隠すより強いし、テーマとも一致します。

書くときの制約：

- 属性（性別・年齢・職業・国籍・信仰）を名指ししない
- 蔑称を使わない。英語でも成立する言い方にする
- **精度より「同じ文に対して割れること」を優先する。**全員同じ反応なら作品は死ぬ

## 画面

写実的な手描きの目を、無機質な8bitの計測器が採寸している。その対比を作っています。

- **目** — ペン画の写実。虹彩の放射線46本、まぶたの折り目、目頭の切れ込み、まつ毛13本。
  線はすべてインクで通し、**色は虹彩の塗りにだけ**乗せる。線を黒に保つほうが、色が付くほど不気味になる
- **配置** — 標本シートの格子。ゆらぎは位置ではなく、まぶたの開きと向きにだけ与える
- **視線** — 100個すべてが中央の投稿欄を向く
- **UI** — ピクセルフォントの計測表示。`OBSERVERS 100/100` `SUBJECT 007` `CONF 42`。
  バーは階調を作らず、マスで数える
- **演出** — 判定が切り替わった目は一度まばたきし、♥（好き）／⟲（有益）／×（うざ・きもい）が浮かぶ
- **ドラッグ** — 引っ張ると格子全体が紙のように波打つ

### 糸をやめた理由

当初は同じ反応をした目どうしを糸で結び、蜘蛛の巣にしていました。やめました。
糸は「同じ反応だった」以上の意味を持たず、有機的な巣は狙っている無機質さと逆方向だったからです。

**ただし物理の拘束としては残しています。** 見えないまま隣どうしを繋いでいるので、
引っ張ると格子全体が波打ちます。

## 実測

すべて実 API に対する計測値です。

| | |
| --- | --- |
| 100判定のレイテンシ | 644〜1062ms（ウォーム時） |
| 1コール | 25,662 tok ＝ **¥0.162** |
| 25人ずつ巡回した場合 | ¥0.04 / コール、同時接続 39人 |

### 同時に打てるのは9人

見落としやすい制約として、**トークンレート上限（250,000 tok/秒）のほうが
リクエスト上限（1,200/分）より先に効きます**。

```
250,000 ÷ 25,662 = 9.7コール/秒
＝ 毎秒投げ直すと、同時に打てるのは9人まで
```

対処として **1ティックにつき25人ずつ、順に回す**設計にしました。コストは1/4、同時接続は39人。
そして**見た目も良くなります**。100個の目が一斉に変わるより、バラバラに瞬くほうが生き物に見える。

技術制約への対処が、そのまま演出の改善になりました。

### 6語彙すべてが発火することの確認

8投稿 × 100人 = 800判定で検証しました。

| 反応 | 出現率 |
| --- | --- |
| どうでもいい | 29% |
| 好き！ | 27% |
| きもい | 17% |
| これは有益！ | 12% |
| うざ | 12% |
| 妬ましい | 3% |

「どうでもいい」が最多なのは狙いどおりです。

## 設計で踏んだところ

### criteria の説明を削ると、作品が死ぬ

`criteria` の説明文を省けば ¥0.162 → ¥0.071 に下がります。判定を比べたら**一致率73%**で、
壊れ方が最悪でした。

```
【病み投稿】
  説明つき:  好き！4 / うざ4 / どうでもいい12   ← 割れる
  null    :  どうでもいい 10/10（確信度0.70〜0.90）← 全員無関心で固定
```

確信を持って全員を「どうでもいい」に倒します。**ルーブリックが判定そのもの**なので削れません。

### 「きもい」がほとんど発火しなかった

当初の定義は `生理的に受けつけない` でした。ハードルが高すぎて、8投稿中2投稿でしか出ない。
**境界の侵犯**として定義し直したら直りました。

```
【夫の残したコーヒーを飲む投稿】
  「生理的に受けつけない」            → きもい  0
  「見たくなかった。他人の内側に触れすぎている」→ きもい 18
```

有益・日常の投稿では 0 のまま動かないので、過剰発火もしていません。
日本のSNSで「きもい」が実際に使われる用法にも近くなりました。

### 100の目は、書いた人間の想像力の外には出られない

検証中にこういう結果が出ました。

```
毎朝、夫の残したコーヒーを飲み干すのが日課です。同じ味を共有できる気がして。
→ 好き！87  きもい0
```

人間なら確実に割れる文です。でも「他人の私物への執着を不気味だと感じる」という態度を
誰も持っていなかったので、その反応が存在しなかった。

**これは作品のテーマそのものが、データとして出てきた瞬間でした。**

## 動かす

```bash
npm install
echo "TYPESAFE_API_KEY=..." > .env.local
npm run dev
```

APIキーはサーバー側でのみ読まれます。

| ファイル | |
| --- | --- |
| `app/page.tsx` | 画面。投稿欄・集計・計測パネル |
| `components/Web.tsx` | canvas。目の描画、物理、ドラッグ、演出 |
| `components/Bar.tsx` | 8bitの目盛りバー |
| `lib/personas.ts` | 100のペルソナと6つの反応語彙 |
| `lib/web.ts` | 配置と物理 |

**現在はモックデータで動いています。** Jev の接続はこれから。
