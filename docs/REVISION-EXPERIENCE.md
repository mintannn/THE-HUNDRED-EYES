# 一文字、消すたびに

> 過去のデザイン記録。入力中の逐次判定は廃止し、明示的な再投稿で瞬きと分析開示を繰り返す。現在の流れは [届くことと、聞こえること](./ATTENTION-EXPERIENCE.md) を参照。

2026-09-22の実装。初回投稿の演出に、同じ100人へ言葉を届け直す時間を加えた。

[書き直し・PC](./previews/rewriting-desktop.png) · [原文の残像・PC](./previews/memory-desktop.png) · [書き直し・スマホ](./previews/rewriting-mobile.png) · [原文の残像・スマホ](./previews/memory-mobile.png)

## 体験

最初の投稿欄は奥へ小さくなり、淡い「遠くへ」が現れる。押すと同じ100人を広く見渡せる。ここでは誰の反応も変わらない。

「書き直す」で同じ目を残し、投稿欄だけが手前に戻る。入力が850ms止まり、日本語変換が確定すると判定する。十分な差のあった目だけに短いまばたきと反射が届く。視線・距離・まぶたは各人の値へ滑らかに動く。部屋全体の露光や開示は繰り返さない。

再投稿すると、文章が再び奥へ残る。最初の投稿を好意的に受け取り、書き直した投稿への関心が十分下がった静かな目があれば、そこにだけ原文が映る。約3.2秒後から現れ、約13秒までに消える。該当する目がなければ出さない。

その後、手が止まると目の位置に人物定義の断片が浮かび、自分の言葉と編集の跡が残る。定義が消え、最後の一行「この百人は、ひとりが書いた。」が現れる。別画面には移らない。編集しなければ一つの文章だけを残す。詳しい時間と操作は [終幕の仕様](./ARTWORK-FINISH.md)。

「最初の言葉」で原文へ戻せる。同じ文章には、セッション内の同じ結果を使う。原文と各版はページのメモリだけに保持し、ページを閉じると失われる。

## 仮判定で試す例

1. `今日はもう頑張れない。` を投稿し、「遠くへ」で全体を見る。
2. 「書き直す」で `今日も頑張ります。` に変え、少し待つ。
3. 再投稿し、ひと呼吸眺める。
4. 再び編集し、「最初の言葉」で戻す。

これはローカルの仮判定の例で、Jev実応答による実測例ではない。

## 判定

- 人数の固定を廃止。無関心・批判・称賛の数を強制せず、個別の結果を数える。
- 全文ハッシュによる再抽選を廃止。同じ人物の関心と声の届く範囲を保つ。
- 関心・好意・不快・表に出したさを独立した4軸にした。好意が強くても黙ることができる。
- パラメータは現在の4軸と、最初の値を示す薄い線。Choiceの確率やconfidenceを感情量として表示しない。
- 人物・心の声・声の届く範囲は作者の設定。実在する人の心の実測ではない。
- 前面の台詞は最大4人の批判、または3人の称賛と2人の冷笑に絞る。表示の密度を制御し、100人分の判定や人数は変えない。

APIキーがない場合は日本語の話題・語調と人物ごとの固定ルールで反応する。任意の文章の意味を理解するモデルではなく、語調の差に反応しないこともある。

## Jev接続

キーがなければ端末内の仮判定だけを使い、文章をサーバーへ送らない。`GET /api/observe` でモードを確認する。

サーバーの `.env.local` に `TYPESAFE_API_KEY` を設定して再起動すると、投稿と編集内容を `POST /api/observe` からTypeSafeへ送る。`.env.example` が設定例。`JEV_MODEL` の既定は `jev-latest`。キーはサーバーだけで使い、`NEXT_PUBLIC_` には置かない。モードは作品情報で確認できる。

一人につき6択のChoiceと4つのScore、合計500問。25人ずつ4件で並列に判定する。各問に人物定義と固定した生活の文脈を添える。100人分の有効な回答がすべて揃ってから反映する。

Scoreは4段階の期待値を0〜1に変換し、Choiceの分布・Scoreのconfidenceと分離する。低確信な変化だけで「最初の好意が失われた」という残像を出さない。

失敗・欠損時は直前の結果を保ち、仮判定へ黙って切り替えない。同文の再利用により、一語の効果と再呼び出しによる揺れを混ぜない。

2026-09-22時点、この作業環境にはAPIキーがなく、実APIの速度・費用・反応品質は未検証。接続後、まず少数の人物と文章の組で実測する必要がある。

## 実装と検証

| ファイル | 役割 |
| --- | --- |
| `lib/experience.ts` | 個別の仮判定、4軸、差分、残像の条件 |
| `lib/use-judgements.ts` | モード確認、同文キャッシュ、リクエストの中断 |
| `lib/jev-server.ts` | 500問とJev応答の検証 |
| `app/api/observe/route.ts` | サーバーの接続口 |
| `app/page.tsx` | 同じ空間での編集・再投稿・原文への復帰 |
| `components/EyesScene.tsx` | 個別の到着、視線と距離、原文の反射 |
| `components/EyePopover.tsx` | 独立した4軸と最初の値 |
| `tests/revisions.spec.ts` | 同じ100人、残像と消失、原文の復帰、IME、通信失敗 |
| `tests/jev.spec.ts` | 問いの構造、独立スコア、欠損拒否、固定分布の撤去 |

ブラウザテストは実APIを呼ばない。Jev経路は合成レスポンスで確認する。PC・スマホ相当のChromiumで体験を、一覧のスクロールはWebKitでも確認する。
