## 中心に置く問い

他人の目を気にして、自分の言葉を変える。その「他人」の輪郭は、誰が決めたのか。

初回の声の偏りと、その後の書き直しを、作者が定義した判断基準に自分を合わせる行為としてつなげる。ただし、編集しない選択や期待と異なる反応にも、別の結論を付けない。

## 終幕

「遠くへ」で全体を見渡したあと、手が8.5秒止まると投稿欄・数値・声が薄れ始める。さらに6秒後、同じ目の質感がほどけ、その位置に人物定義の短い断片が現れる。

100人それぞれの断片は `PERSONAS.ja` の部分文字列で、Jevへ渡す人物定義と対応する。モデルの内心や推論を生成・表示しているわけではない。PCは最大14個、スマホは最大8個を、重ならない位置から読むことができる。各断片は元の目の座標に留まり、画面端のみ内側へ寄せる。全定義は「百の内側」で読める。

中央には実際に受け取られた文章が残る。最初と最近2版をメモリに保持し、現在の文とは異なる過去の版を、最大2層の跡として見せる。取り消された文字はUnicode単位の差分で示す。長い過去の文は2行の断片になる。現在の文は140文字すべてを表示する。編集しなかった人には一つの文章だけが残る。

判断基準が現れて8秒後、それらが先に消える。4.5秒の間を置いて、最後の一行が約5秒かけて浮かぶ。

> この百人は、ひとりが書いた。

これは作者による人物定義を指す。Jevの学習内容やすべての判定結果を一人が手で書いた、という意味ではない。「作品について」にもこの範囲を明記した。

「現実へ」は「遠くへ」へ変更した。開示後も作者とJevが構成した判断であり、現実の世論との答え合わせにはしない。

既存の原文の反射は、その目の関心が実際に離れたときだけ先に現れ、終幕へ進む頃には消える。別画面・新しい部屋・新しい判定は作らない。ポインター、タップ、キー、ホイールの操作で表示を戻し、その入力自体も通常の操作として届く。同じ100人・判定・投稿・キャンバスを保つ。

パラメータ・作品情報・一覧を読んでいる間、動きを停止している間、タブを離れた間は進めない。戻った際は待ち時間もやり直す。動きを減らす設定では自動進行を止め、小さな「余韻」から、判断基準・言葉・一行を静止画として同時に見られる。WebGL喪失時も軽量表示で体験できる。

常設の数値は小さく淡くした。触れる・フォーカスすることで読みやすくなり、個別のパラメータと一覧は引き続き利用できる。

## Jevを作品の構造として伝える

Jevは、同じstateに対して異なる問いを独立・並列に評価し、ChoiceやScoreとして結果を返す。作者が決めた選択肢・判断基準と、モデルが実際に返す判定を作品の素材にする。

「AIだと知らなかった」という種明かしに依存しない。仕組みを知っていても、その判断に合わせて来場者が言葉を変えてしまうことに関心を置く。

Jevの名前だけで技術の必然性を説明せず、判断基準とその判定が目の動きに対応していることを終幕で見えるようにする。「他の技術では不可能」という主張はしない。

## 作品解説

「作品について」に制作年、技法、作者が設定する範囲、接続状態を置いた。Jev接続時と仮判定時で説明を切り替える。現在は「接続を想定した」「仮判定版 · Jev未接続」と表示し、入力が端末内だけで扱われることを明示する。接続時はTypeSafeへの送信を表示する。

> 『衆目』は、作者が定義した百の視点で、ひとつの投稿を受け取る作品です。Jevがそれぞれの基準に沿って返す判定を、視線、距離、光、沈黙へ変換します。来場者は反応を眺め、言葉を書き直すことができます。目の奥にある判断基準と、自分が書き換えた文章が同じ場所に残ります。

作品名の近くや体験後の「作品について」には、次を簡潔に添える。

> 衆目 / THE HUNDRED EYES<br>
> Jev / TypeSafe System One を用いたインタラクティブ・メディアアート<br>
> 2026

## 検証と残る確認

`tests/afterglow.spec.ts` は実時間で初回投稿・距離・定義・消失・一行・操作復帰を確認する。`tests/ending.spec.ts` は編集した文章の跡、動きの抑制、読む間の停止、320px幅・長文・軽量表示を確認する。`tests/ending-data.spec.ts` は定義との一致とUnicodeの差分を確認する。ブラウザテストは実APIを呼ばない。

2026-09-22の結果：

- 終幕・文字の来歴の初回確認：9 passed / 3 skipped。PC・スマホ。
- 既存体験の回帰確認：29 passed / 4 skipped。投稿・編集・通信失敗・100人の判定保持・透明パネル・一覧スクロール。Chromiumと、一覧についてWebKit。
- 最終調整後：4 passed。編集の残像から終幕までの実時間の流れ、終幕中にWebGLを失った場合の軽量表示、操作復帰をPC・スマホで確認。
- `npm run build` と `npm run lint` は成功。スキップは画面サイズと無関係な処理の重複実行、またはスマホ専用条件。

Jev実応答で、意外な分布・変化しない投稿・低確信・通信待ちでも体験が成立するかは、APIキーの設定後に確認する。現在は未検証。

初見の数人に説明なしで体験してもらい、「何が起きたと思ったか」「どの瞬間が残ったか」を聞くことも残る。特定の感想を正解にしない。
